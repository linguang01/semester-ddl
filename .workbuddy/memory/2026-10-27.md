## 手机端「改完代码不更新」彻底完善
- 根因分析（三个叠加）：①CDN 边缘缓存 sw.js，浏览器拿旧脚本发现不了新版本；②应用只在「打开页面」时被动等浏览器检查更新，PWA 常驻后台不触发；③无版本号展示，无法核对手机上的版本。
- 新增 `src/pwa.ts`：`registerSW`（virtual:pwa-register）接管注册；`onRegisteredSW` 里挂 ①每小时 `registration.update()` ②`visibilitychange` 切回前台检查（60s 限流）③`online` 恢复检查；`onNeedReload` 接管刷新时机：后台/启动 30s 内/手动检查 30s 内→立即刷新，否则延迟到切后台（最多 2 分钟）避免打断输入。dev 模式 `import.meta.env.DEV` 跳过注册。
- `vite.config.ts`：`define` 注入 `__APP_VERSION__`/`__BUILD_GIT_HASH__`（execSync git rev-parse --short HEAD）/`__BUILD_TIME__`；显式 `injectRegister: 'auto'`（检测到 virtual import 后不再注入 registerSW.js，改打包 workbox-window 进主 JS）。
- SettingsSheet 新增「版本与更新」区块：展示版本号+git hash+构建时间，「检查更新」按钮 → `checkForUpdate()` 返回 updated/latest/offline/unsupported/error → toast。
- 新建 `vercel.json`、更新 `edgeone.json`：sw.js/index.html/manifest.webmanifest → `Cache-Control: no-cache`；/assets/* → 一年 immutable。⚠️ edgeone.json 的 headers 字段 schema 未经线上验证，若部署报错删除该字段改控制台配置。
- README 新增「应用更新机制（重要）」章节；package.json 版本 0.1.0→0.2.0。
- 关键提示给用户：装到主屏幕的 PWA 绑定域名，临时预览链接/换域名部署不会更新旧安装；必须固定域名+HTTPS。
- 验证：npm run build 通过（版本号 63ba7e3、updatefound/visibilitychange/36e5 等均确认打入产物）；dev server 启动正常、pwa.ts 可转换；构建产物 sw.js 仍含 skipWaiting/clientsClaim/cleanupOutdatedCaches/NavigationRoute。

## 结合 DeepSeek 对话与 EdgeOne 实测，定位「重新搭建」真因并完善
- 用户提供了 DeepSeek 对话分享链接（浏览器 agent 提取 3 轮）+ 2 张截图（EdgeOne Pages 控制台预览地址弹窗、手机旧版设置面板）。
- 实测确认：`semester-ddl.edgeone.dev/sw.js` → **401（X-EOP-MSG: eo_time missing）**＝24 小时鉴权预览链接，过期即死；`semester-ddl.edgeone.app` → 404（该名下无部署）；`*.vercel.app` 大陆 ERR_CONNECTION_TIMED_OUT（对话中已确认）。
- 真因结论：手机 PWA 装在了 24h 过期的 edgeone.dev 预览链接上 → 链接过期 401 → 只能重装（「重新搭建」）；换 Vercel 又被墙（「不行噢」）；用户误以为必须买自定义域名（「要花钱得不偿失」）。手机截图设置面板无「版本与更新」→ 手机一直是旧版本，「短哈希没看到」。
- 改进 ①：SettingsSheet「版本与更新」新增**当前访问地址展示 + 临时地址警告**（模块级正则 `/(^|\.)edgeone\.dev$|(^|\.)vercel\.app$/i`，命中显示琥珀色警告：请迁移固定生产域名重装）。
- 改进 ②：pwa.ts 补 `pageshow`(persisted) → bfcache 恢复时补一次 update 检查（iOS PWA 不触发 visibilitychange 的场景）。
- 改进 ③：README 部署章节重写为「部署：用一个固定、国内可访问的 HTTPS 地址」：三条铁律（预览链接不能装 PWA／Vercel 大陆被墙／必须 HTTPS）；主推 EdgeOne Pages 免费默认生产域名（*.edgeone.app，无需备案，push 自动部署）；手机迁移三步（删旧图标→固定域名重装→设置里核对版本）。
- 构建验证通过：当前访问地址/迁移警告/pageshow 均确认打入 dist 产物（正则转义形式 edgeone\.dev）。
- 待用户操作：EdgeOne 控制台部署详情里找 Production 默认域名 → 手机删旧图标 → 固定域名重装一次 → 之后 push 自动更新。
