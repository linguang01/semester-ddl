## PWA 缓存问题彻底修复（推翻 prompt 方案）
- 根因复盘：prompt 模式新 SW 卡 waiting，需用户点 Toast 才 skipWaiting，手机端不点 → 永远旧版本。且 sw.js 被 EdgeOne 边缘缓存，浏览器 fetch 到旧 sw.js 根本不触发更新。
- `vite.config.ts`：`registerType` 改回 `autoUpdate`，workbox 显式加 `skipWaiting: true` + `clientsClaim: true`。
- 删除 `components/UpdatePrompt.tsx`，`main.tsx` 移除其挂载（autoUpdate 无需手动 skipWaiting）。
- `index.html` 加一次性缓存救援脚本：`localStorage['ddl-sw-migrate']!=='v2'` 时注销所有 SW + 清空 Cache Storage + reload，之后打标不再重复；无 SW 则直接打标不 reload。递增 MIGRATE_VERSION 可再次强制清理。
- 关键认知：`selfDestroying: true` 是「自毁 PWA」（unregister+清缓存+移除），不是「强制更新」，勿混淆。
- EdgeOne 待办（用户手动）：①SPA 回退规则（catch-all → /index.html）解决 /?v=2 404；②sw.js/index.html/manifest 配 Cache-Control: no-cache，/assets/* 配 immutable 长缓存。
- 构建通过（vite-plugin-pwa 2.0.0），dist/sw.js 已含 skipWaiting/clientsClaim。

## 快速添加（Quick Add）自然语言解析
- 新增 `src/utils/parseQuickAdd.ts`：`parseQuickAdd(input, now?)` → `{ title, deadline, hasDate, hasTime }`。
  - 日期：今天/明天/后天/大后天/周末(→周六)/周X/星期X/礼拜X/X号/X日；时间：HH:MM、X点、X点半、X点Y分，可带 上午/下午/晚上 等时段前缀。
  - 未识别日期→今天；未识别时间→23:59。日期「已过」自动顺延（周X→下周，X号→下月）。
  - 标题清理：剥离日期/时间片段 + 去标点 + 去掉开头「交/提交/上交」(`(?=.{2,})` 防误伤「交通」)。
  - 时段换算：下午/晚上/中午 hour<12 时 +12；凌晨/午夜 12点=0点；无前缀按 24h 原样（「3点半」→03:30，已作为盲点提示）。
- `TaskFormSheet`：新增任务默认 DDL 由「明天 23:59」改为「今天 23:59」（对齐「默认今天」）；标题 onChange 实时解析回填 deadline（仅 hasDate||hasTime 时，避免覆盖手动选的时间）；onBlur 剥离标题；handleSubmit 兜底再解析一次 title（仅新增任务；编辑时不解析）。
